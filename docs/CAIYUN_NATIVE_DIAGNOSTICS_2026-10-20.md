# 彩云原生地图跟进核对

## 当前结论

现有降雨预报助手只提供独立网页。彩云诊断分支返回空改写结果，保留原响应；没有实现原生地图替换。手机连接成功不会改变这一行为。

通过已配对 iPhone 的 USB 安装服务只读查询确认：彩云天气为 **7.63.2（6）**，Loon 为 **3.5.2（1005）**。Xcode 设备工具能识别手机，但其 App 查询因未开启开发者模式而失败；上述版本使用另一只读 USB 接口取得，未开启开发者模式。

手机界面已确认安装“彩云天气去广告”，插件说明仅列广告移除。彩云会在截屏后自动打开分享图片面板，影响镜像检查。尚未取得该版本存在“截屏分享”本地开关或服务端开关的证据，不能发布猜测字段的 Loon 改写规则。

## 本次诊断改进

- 已知雷达路径支持 `v2.6` 等小数版本；仍只匹配原有四个 API 域名和 `radar`、`nafp`、`satellite` 三个前缀。
- 输出固定脱敏路由模板、HTTP 状态、归类 MIME 和正文字符数，数组采样可显示元组中各位置的类型。
- 不输出载荷标量、未知字段名、请求头、完整 URL、坐标或鉴权信息；原生响应保持不变。
- 明确结构展开上限与 Loon 自身日志保留行为。
