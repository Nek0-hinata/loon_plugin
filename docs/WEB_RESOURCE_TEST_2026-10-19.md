# 网页图片与资源测试：2026-10-19

## 4KHD 图片问题与修复

本次检查了当前首页、搜索结果和两个抽样详情页，以及站点的 `/interstitial.js`、`/js/config.js`、页面脚本与样式。只读取公开 HTML、JavaScript、CSS 和资源响应头，没有截图或执行远端页面脚本。

原站脚本除了投放广告，也会把 HTML 内的 `https://i0.wp.com/pic.4khd.com/-…/*.webp` 转换为 `https://i0.wp.com/yt4.googleusercontent.com/-…/*.webp`，并还原路径中的 `l/AAAAA`、`AsHYQ` 标记。旧版插件注销该脚本的 Service Worker，却没有单独保留图片转换，因而可能导致封面和正文图片加载失败。本次抽取字符串表复核转换逻辑，没有执行整个远端脚本。

抽样的 24 个原始地址在当前测试网络均返回 HTTP 429；按站点逻辑修正后，24 个地址全部返回 HTTP 200，响应类型为图片。HEAD 检查没有下载或显示图片，不能代替手机端的实际解码与显示验证。

修正仅作用于启用 4KHD 时、已识别的代理路径和图片文件，覆盖图片 `src`、延迟加载属性、原图链接和图片预览元数据。原始图片尺寸、查询参数、页面布局和延迟加载保持完整。其他来源的图片及脚本、注释、CSS 内的文字不进行替换。不恢复原广告脚本、统计请求或域名测速。

## 已知限制

- Pornhub 抽样详情页的订阅按钮含有 `data-label="subscribe_button""` 这类不规范标记，当前解析器会放弃整页改写并保留原响应。该页不会获得本插件的正文去广告；没有擅自修补站点原始 HTML。
- Jable 与 MissAV 的防护验证限制了当前正文检查，不将 HTTP 403 当作插件故障或测试通过。
- 未执行真实视频播放、付费账号操作、浏览器截图或手机端 Loon 验证。图片服务的返回结果还可能随访问地区、网络、限流与时间变化。
- 其他插件、主配置中的拒绝规则或旧版本仍可能独立误拦图片，不受本插件的单站开关控制。
